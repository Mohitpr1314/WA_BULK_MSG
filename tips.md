# WhatsApp Automation Script

## Important Considerations

### WhatsApp Web Behavior
Ensure that WhatsApp Web is fully loaded and that you have scanned the QR code before the script starts sending messages. The script waits for the QR code scan before proceeding, but it's essential to confirm that the WhatsApp Web interface is fully functional.

### Network Issues
Ensure that your internet connection is stable to avoid interruptions. A stable connection is critical to prevent the script from failing when trying to interact with WhatsApp Web.

### Long-Running Script
Since the script needs to keep running to execute scheduled tasks, consider running it in a stable environment, such as a server or a dedicated machine. This will ensure the script is always running and can send messages as scheduled without unexpected shutdowns.

---

## How to use the `requirements.txt`

1. **Install the dependencies** by running the following command in your terminal:

    ```bash
    pip install -r requirements.txt
    ```

This will install all the necessary libraries to run the WhatsApp automation script.
